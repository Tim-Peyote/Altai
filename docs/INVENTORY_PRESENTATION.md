# Altai — инвентарь и предпросмотр персонажа

8 сентября 2026. Согласованная композиция: предметы и фильтры слева, вращаемый персонаж с ячейками снаряжения в центре, описание выбранного предмета справа. Сверху слева — общие вкладки «Инвентарь» и «Карта».

## Сохранённые визуальные ассеты

| Ассет | Редактор и назначение |
|---|---|
| `UI/WBP_FieldInventory` | UMG Designer: основной экран, три области, вкладки, фильтры и действия |
| `UI/WBP_InventoryItem` | UMG Designer: иконка, название и количество предмета |
| `UI/WBP_EquipmentCell` | UMG Designer: ячейка одежды или быстрого доступа |
| `UI/WBP_PreviewSurface` | UMG Designer: изображение захвата и область поворота мышью |
| `UI/WBP_FieldMap` | UMG Designer: отдельный экран карты; пока без исследованных областей |
| `Maps/L_Preview_Inventory` | Level Editor: отдельный стенд модели, камеры и света |
| `UI/Preview/BP_InventoryPreviewRig` | Blueprint Viewport: модель, поза, свет, камера и параметры захвата |
| `UI/Preview/RT_InventoryPreview` | Render Target Editor: разрешение захвата |
| `UI/Preview/M_InventoryPreview` | Material Editor: вывод захвата в UI |
| `Items/DA_StartingInventory` | Data Asset Editor: предметы, категории, иконки и допустимые ячейки |

Все пути относительны `/Game/Altai`. Ассеты открываются отдельно без прохождения кампании. Компоновка сохранена в UMG, постановка — в Blueprint и карте. `Scripts/Editor/create_inventory.py` служит для авторинга; при запуске игры он не исполняется. Старый простой `WBP_Inventory` сохранён, но контроллер использует `WBP_FieldInventory`.

## Поведение

- I / Tab — открыть или закрыть инвентарь. M из мира открывает карту; внутри экрана переключает две вкладки.
- Сумка без фиксированного ограничения по числу ячеек. Сетка в четыре столбца растёт вниз внутри `ItemScroll` (ScrollBox); колесо мыши и полоса прокрутки открывают нижние ряды. Фильтры, описание и персонаж остаются неподвижными. При смене фильтра прокрутка возвращается наверх.
- Фильтры: все предметы, материалы, экипировка, снаряжение. Фильтр не меняет состав сумки. Пустая категория очищает описание и отключает назначение.
- Выбор ячейки обновляет название, категорию, иконку, описание, количество и допустимые действия справа.
- Поворот персонажа — перетаскиванием мышью по центральной области; стрелки влево/вправо дают дискретный поворот.
- Ячейки: голова, одежда, предмет в руке, два места быстрого доступа. Это начальный набор, а не утверждённая финальная система экипировки.
- Сначала выбрать предмет, затем нажать совместимую ячейку либо кнопку назначения справа. Совместимые ячейки подсвечиваются. ПКМ по предмету или занятой ячейке открывает контекстное меню с допустимыми действиями; справа также доступна кнопка «Снять назначение».
- ЛКМ с перемещением — перенос предмета из сумки в совместимую ячейку. Перенос между занятыми ячейками меняет назначения местами, если оба предмета совместимы. Перенос из ячейки обратно в сумку снимает назначение. Неподходящая цель или отпускание вне цели отменяют перенос.
- Сортировка кнопкой или R: тип → имя → количество. Меняется только порядок отображения; идентичность выбранного предмета, количество и назначения сохраняются. Выбор предмета не перестраивает сетку и не сбрасывает прокрутку.
- В контекстном меню можно выбрать конкретную быструю ячейку, надеть предмет или снять назначение. Недоступные действия скрыты. Escape сначала закрывает контекстное меню.
- Один предмет назначается в одну ячейку. Переназначение не создаёт копий и не расходует количество. После удаления последней единицы назначение очищается.
- Назначения сохраняются в активном прохождении вместе с предметами и вызывают автосохранение. Старые записи без назначений открываются с пустыми ячейками.

## Предпросмотр

Показывается стандартный манекен Unreal в спокойной позе. Используется SceneCapture2D → Render Target → UI-материал. Во время инвентаря создаётся экземпляр авторского rig вдали от игрового пространства. Захват ограничен компонентом модели; студийные источники и модель используют отдельный канал освещения. Поворот меняет только предпросмотр, а не героя или его камеру.

Захват выполняется при открытии и повороте, без постоянной съёмки каждого кадра. Состояние рендера сохраняется между захватами для корректной экспозиции; фон и свет неба исключены. Изображения вписываются с сохранением пропорций. При закрытии виджета runtime-rig уничтожается. Карта-стенд не загружается как часть игрового мира: она предназначена для визуального редактирования и проверки того же Blueprint.

## Границы текущего шага

В стартовом наборе остаются камень, волокно и пустая фляга. Для них созданы собственные простые иконки; исходник генерации хранится в `SourceArt/Inventory`. Фляга допускает быстрый доступ; материалы не экипируются. Одежда и оружие пока не добавлены в игровой контент — соответствующие ячейки пусты. Метаданные и проверка совместимости готовы для их подключения.

Назначение предмета пока не добавляет лечебных эффектов, анимаций применения или новой одежды на манекене. Эти механики требуют собственных правил и ассетов. Карта содержит честное пустое состояние; генерация карты, исследование, метки и масштабирование ещё не подключены.

Палитра сдержанная: сплошной чёрный фон (RGB 0, 0, 0), совпадающий с фоном предпросмотра, светлый текст и тёплый акцент выбранных элементов. Для художественного наполнения сохранять естественные цвета и материалы Altai; базовая геометрия интерфейса не зависит от замены модели и иконок.

Единое оформление всех экранов описано в [UI_STYLE](UI_STYLE.md).
