# Управление экранами полигона

| Действие | macOS | Windows |
|---|---|---|
| Инвентарь | I / Tab | I / Tab |
| Панель разработчика | Command+D | Ctrl+D |
| Закрыть инвентарь | I / Tab / Esc | I / Tab / Esc |
| Закрыть панель разработчика | Command+D / Esc | Ctrl+D / Esc |

Клавиши действуют во время игры, когда фокус находится в игровом окне. В редакторе вне PIE сочетания принадлежат самому редактору.

Контроллер полигона использует общую систему экранов. Автоматический переход к главному меню для полигона отключён. Инвентарь приостанавливает симуляцию, блокирует управление и не открывается поверх панели разработчика. Закрытие восстанавливает управление и предыдущее состояние паузы.

Unreal 5.8 в UPlayerInput::IsCtrlPressed сопоставляет логический Ctrl с Command на Mac, а FMacApplication выполняет соответствующее сопоставление для Slate. Поэтому игровая привязка и обработчик закрытия остаются на логическом Ctrl; подпись выбирается по платформе. F1 не используется.

Проверка на Mac: сборка успешна, review_lab_inventory.py проверяет создание экрана, паузу, исключение перекрывающихся панелей и возврат управления. В PIE визуально проверены открытый экран, закрытие через I и открытие/закрытие через Tab. Windows проверен по привязке и коду движка; запуск на Windows не выполнялся.
