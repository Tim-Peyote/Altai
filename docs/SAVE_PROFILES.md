# Прохождения и сохранения

Согласованная модель Altai: отдельные прохождения с автосохранением внутри каждого. Общего прогресса между членами семьи нет. Это не набор ручных снимков одной кампании.

## Меню

- **Новая игра** — игрок задаёт имя; создаются новый идентификатор и отдельный файл. Имя не используется как путь. Совпадающие имена допустимы и не ведут к перезаписи. При пустом имени запуск отменяется; сохраняются первые 32 символа.
- **Продолжить** — последнее выбранное для игры прохождение. Выбор сохраняется отдельно от даты записи. Если выбранное прохождение недоступно, используется самое свежее читаемое.
- **Загрузить игру** — список по дате сохранения: имя, время игры, текущая карта и дата. Выбор меняет активное прохождение; чужие файлы не затрагиваются.
- **Сохранить и выйти в меню** — новая запись только активного прохождения, затем меню. При ошибке игрок остаётся в паузе и видит сообщение.
- **Выйти без сохранения** — дополнительный выход из игры с подтверждением. Новая запись не создаётся. Изменения после последней записи теряются; сделанные ранее автосохранения остаются.
- **Выход** в главном меню — закрыть приложение.

Фиксированного лимита числа прохождений в прототипе нет; список прокручивается. Удаление и переименование пока не реализованы.

## Запись текущего прототипа

Сохраняются позиция персонажа, направление камеры, предметы и назначения экипировки/быстрого доступа, имя, время игры и дата записи. Автосохранение запускается после изменения предметов или назначений и каждые 30 секунд игрового времени. Этот интервал — настройка нашего прототипа. В паузе игровой таймер и учёт времени не идут. Успех кратко показывается в HUD; ошибка остаётся до следующей успешной записи.

Запись синхронная: для текущего небольшого снимка. Перед увеличением объёма мира потребуется очередь асинхронной записи и согласованный снимок владельцев состояния. Смерть, контрольные точки, лаборатория и переходы миров ещё не реализованы и не имеют выдуманных правил автосохранения.

## Хранение и восстановление

- Обычная игра: `Saved/SaveGames/Profiles/Profile_<GUID>.sav`.
- PIE: отдельный каталог `Saved/SaveGames/EditorProfiles`.
- `LastPlayed.sav` хранит выбор для «Продолжить».
- Перед обновлением создаётся `.bak` из предыдущей читаемой записи. Новый файл сначала пишется во временный `.tmp`, затем перемещается на основной путь и проверяется чтением.
- Если основной файл не читается или имеет неверные данные, пробуется резервный. В списке такой профиль отмечен «резервная копия». При повреждении обеих копий профиль не предлагается для загрузки; файлы не удаляются.
- Версия формата — 2. Старые `Altai_Expedition_v1.sav` и `Altai_EditorExpedition_v1.sav` импортируются в соответствующий каталог как «Первое прохождение»; исходники сохраняются неизменными. Повторный импорт предотвращается меткой в профиле.
- Прямой Play из `L_World` без выбора прохождения не пишет пользовательские сохранения.

## Визуальное редактирование

`WBP_NewGame`, `WBP_LoadGame`, `WBP_ProfileRow`, `WBP_ConfirmExit`, `WBP_GameHUD` — обычные сохранённые UMG Blueprint-ассеты. Их можно открыть отдельно в Designer. Код связывает действия и данные с элементами. `Scripts/Editor/upgrade_save_ui.py` используется только для авторинга, а не при запуске игры.
