# Altai — проект на Unreal Engine

Исходный пакет собран 8 сентября 2026 года: восемь основных документов и манифест передачи. После чтения внесены уточнения пользователя: Unreal Engine выбран для новой реализации; первую лабораторию герой находит как базовый полевой очаг, а сложные приборы получает через развитие.

Начать с [состава пакета](docs/NEW_ENGINE_HANDOFF.md), затем [концепции игры](docs/GAME_DESIGN.md).

Визуальная постановка и инвентарь: [композиция и реализация в Unreal](docs/INVENTORY_PRESENTATION.md).

Обязательное разделение на модули и отдельные редактируемые сцены описано в [MODULAR_ARCHITECTURE](docs/MODULAR_ARCHITECTURE.md). Конкретная схема для Unreal, работа со звуком и открытие каждой композиции в редакторе — [UNREAL_ARCHITECTURE](docs/UNREAL_ARCHITECTURE.md). Устройство лаборатории пока обсуждается; перенос и проявление не закреплены.

`Altai.uproject` — первый игровой каркас для Unreal Engine 5.8.2: главное меню, отдельный пустой мир, стандартный персонаж и простой инвентарь. [Запуск, управление и список ассетов](docs/PROTOTYPE_STATUS.md). [Отдельные прохождения, автосохранения и варианты выхода](docs/SAVE_PROFILES.md). Включены встроенный Unreal MCP и All Toolsets. Настройка и проверка соединения: [UNREAL_MCP_SETUP](docs/UNREAL_MCP_SETUP.md).

Созданы пять C++-модулей и базовые редактируемые карты/виджеты. Персонаж и анимации взяты из установленного шаблона Unreal. Лаборатория, биомы и основные механики ещё не реализованы. Открытые продуктовые решения перечислены в манифесте; рабочие предложения в документах не означают утверждённый баланс.

Отдельный [полигон персонажа](docs/CHARACTER_LAB.md): `/Game/Altai/Debug/Maps/L_CharacterLab` — сцена движения, проверки камеры, будущего контакта рук и физических предметов. Открывается непосредственно в редакторе и запускается без прохождения.
