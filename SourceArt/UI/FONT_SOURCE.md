# Шрифт интерфейса

Cormorant Garamond из репозитория Google Fonts: https://github.com/google/fonts/tree/main/ofl/cormorantgaramond

Исходный файл `CormorantGaramond[wght].ttf` сохранён как `AltaiHeading.ttf`; данные шрифта не изменялись. Лицензия SIL Open Font License 1.1 находится в `FONT_LICENSE.txt`. Для заголовков и меню создаются ассеты FontFace и составного Font. Основной мелкий текст остаётся на Roboto с кириллицей.
